WHAT IS STILL OUT OF SCOPE
==========================

The regular campaign loop now works: hub → start checklist → initiative
(setup) → Begin round 1 → turns that skip the dead → Finalize (XP to
combatants, optional loot holder) → hub, with optional typed short rest.

This file is what this app still does not do on purpose. None of these are
required to run a normal night at a real table.


1. RULES ENGINE
---------------

Already handled: Extra Attack / Multiattack, two-weapon fighting, opportunity
attacks, Dash (adds your speed to movement left), Disengage, Dodge, Help,
Ready, free object interaction, Grapple / Shove, spell-slot spend on Cast
Spell, concentration saves when hit, half / three-quarters cover, and Hide.

Still not automatic: legendary / lair action economy (legendary actions are
stat-block text only), hidden initiative, poison clocks, condition expiry,
and 5-10-5 diagonal costing. Conditions other than the ones above are
labels you add and remove. Dice stay physical.
A separate non-combat Challenge scene mode (skip initiative) does not exist.


2. VTT EXTRAS
-------------

Already handled: AoE templates (circle, cone, line, cube) and a ruler — both
DM-only aiming aids, not synced to players or saved. Map props, freehand
terrain paint, grid alignment for pre-gridded images, and token portraits.

Still missing: hex grids, token animation, sound, multiple maps in one fight,
OCR of photos, bundled portrait art for SRD monsters, or an external monster
API. Fog is day/night/inside with darkvision range and walls blocking sight —
not a full lighting engine.


3. CHARACTER BUILDING
---------------------

Sheets store what you type or import from a PDF. There is no full builder,
feat picker, inventory manager, or automatic class features (Attacks per
Action and the Rogue / Monk bonus-action filter are the only class-aware bits).


4. HOSTED PROJECTS
------------------

New projects that ran the current schema.sql already have everything.

Existing Supabase projects that predate a feature need its migrate file
(see the full list in supabase/README.md). The ones added most recently:
